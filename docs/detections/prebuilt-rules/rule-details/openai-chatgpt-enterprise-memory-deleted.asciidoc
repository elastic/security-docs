=== OpenAI ChatGPT Enterprise Memory Deleted

Detects ChatGPT Enterprise audit events that delete stored memory. Adversaries may delete memory entries to remove evidence of prior prompts, preferences, or staging instructions after misuse.

==== Investigation guide



*Triage and analysis*



*Investigating OpenAI ChatGPT Enterprise Memory Deleted*


A ChatGPT Enterprise memory entry was deleted. Memory deletion can remove persisted context that would otherwise help explain prior conversations or automated behavior.

Escalate when deletion follows unusual chat activity, credential exposure, or other defense-evasion signals from the same user. Close as a false positive for routine user-driven memory cleanup.


*Possible investigation steps*


- Identify the user and memory identifiers on the alert.
- Review the user's recent conversation and Codex activity for sensitive content or policy-violating use.
- Correlate with mass conversation deletion, shares, or downloads nearby.
- Ask the user whether the deletion was intentional only after reviewing surrounding activity.


*False positive analysis*


- Users commonly delete individual memories while managing personalization settings.


*Response and remediation*


- Preserve remaining audit history and investigate the actor's recent conversations if the deletion appears tied to concealment.


==== Setup



*Setup*


This rule requires the OpenAI ChatGPT Enterprise integration to collect compliance logs into Elasticsearch.

https://www.elastic.co/docs/reference/integrations/openai_chatgpt_enterprise


==== Rule query


[source, js]
----------------------------------
from logs-openai_chatgpt_enterprise.audit_log-* metadata _id, _version, _index
| where
    data_stream.dataset == "openai_chatgpt_enterprise.audit_log" and
    event.action == "delete_memory"
| keep
    _id, _version, _index, @timestamp, event.action, user.id, user.email, source.ip,
    openai_chatgpt_enterprise.audit_log.action_data.memory_id,
    openai_chatgpt_enterprise.audit_log.action_data.auth_user_id,
    openai_chatgpt_enterprise.audit_log.action_privilege, data_stream.*

----------------------------------
