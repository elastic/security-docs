=== OpenAI ChatGPT Enterprise Unusual MCP App Activity

Detects the first time a ChatGPT Enterprise MCP app name is used by a given user email within an organization in the rule history window. MCP apps connect ChatGPT to external systems and can move organizational data into third-party tools. Alerting on first-seen organization, user, and app id triples highlights new or unexpected connector usage rather than every routine approved MCP request. App name is still required in the query for investigation context.

==== Investigation guide



*Triage and analysis*



*Investigating OpenAI ChatGPT Enterprise Unusual MCP App Activity*


First-seen MCP app name for this `organization.id` and `user.email` within the rule history window. MCP apps can move organizational data
into third-party tools.

Escalate when the app is not in the approved inventory, the query looks like bulk data access, or the user recently
had suspicious authentication activity. Close as a false positive when the app is approved for that user.


*Possible investigation steps*


- Identify the user and app (`openai_chatgpt_enterprise.app_log.app_name`, `app_id`).
- Review `openai_chatgpt_enterprise.app_log.query` and conversation identifiers when present.
- Confirm whether the app is approved for the workspace and whether OAuth links for that app are expected.
- Correlate with app-auth link events, conversation shares, or file downloads from the same user nearby.


*False positive analysis*


- Approved MCP apps generate routine request logs. First-seen alerts often reflect a user adopting an already-approved
  connector.


*Response and remediation*


- Disable unauthorized MCP apps, revoke linked credentials, and review conversation context for sensitive data
  exposure.
