|<<prebuilt-rule-8-19-25-google-workspace-user-sign-in-from-atypical-device-type, Google Workspace User Sign-in from Atypical Device Type>> | Detects the first time a Google Workspace user is observed authenticating from a device of a given type (e.g., WINDOWS, MAC, ANDROID, IOS, LINUX) within a historical window.
