=== ESXi Virtual Disk Files Enumerated

Detects a shell search under `/vmfs/volumes` for virtual disk and snapshot files (`vmdk`, `vmsn`, `vmsd`). Those files are the guest disks and their on-host recovery points. Listing them builds the set of files a later process can encrypt or delete.

==== Investigation guide



*Triage and analysis*



*Investigating ESXi Virtual Disk Files Enumerated*


The datastore path and the vmdk family of extensions are how ESXi ransomware chooses what to encrypt. The search itself does not change files.


*Possible investigation steps*


- Read the exact find arguments in message, including any -name filter.
- Correlate with later vm process kill, power.off, or snapshot.removeall from the same session.
- If the command stands alone during a known support window, it is often benign.


*False positive analysis*


Support bundles and storage reports list virtual disks. Escalation is for a search followed by VM shutdown or snapshot deletion.


*Response and remediation*


- If the same session starts killing VMs or deleting snapshots, isolate the host.
- Otherwise record the account and command for hunting across other ESXi hosts.
