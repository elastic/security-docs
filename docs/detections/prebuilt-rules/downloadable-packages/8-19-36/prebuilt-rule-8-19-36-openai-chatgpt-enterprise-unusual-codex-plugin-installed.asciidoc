=== OpenAI ChatGPT Enterprise Unusual Codex Plugin Installed

Detects the first ChatGPT Enterprise Codex plugin install for a given plugin display name and plugin name pair within the rule history window. Newly installed Codex plugins expand the tools and data sources available inside agent sessions; adversaries can enable unexpected connectors to persist access to mail, chat, or file systems after initial compromise.

==== Investigation guide



*Triage and analysis*



*Investigating OpenAI ChatGPT Enterprise Unusual Codex Plugin Installed*


A Codex plugin was installed for the first time for this plugin pair within the rule history window. Plugins can add
connectors that pull mail, chat, or file content into Codex sessions.

Escalate when the plugin is not on the approved inventory, the installing user is unexpected, or nearby activity shows
sensitive search bursts, MCP tool abuse, or access-token creation. Close as a false positive for approved connector
rollouts.


*Possible investigation steps*


- Record `plugin_display_name`, `plugin_name`, and the installing user (`user.email` / `user.id`).
- Confirm whether the plugin is approved in your ChatGPT Enterprise or Codex workspace inventory.
- Review nearby Codex and app-log activity for the same user for MCP calls, Drive or Slack query bursts, or credential
  exposure.
- Search for the same plugin installed by other users to distinguish org-wide rollout from a single anomalous install.


*False positive analysis*


- Planned enablement of common plugins (Slack, Gmail, Google Drive) during onboarding or team pilots.


*Response and remediation*


- Remove unauthorized plugins, revoke related OAuth links, and review data accessed after the install.
- If sensitive data may have been retrieved, follow your data-incident process for the session window.
