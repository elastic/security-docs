=== Potential Prompt Injection Coercing Shell Execution

Detects shells or scripting interpreters launched from a parent command line that contains common LLM prompt-injection or jailbreak language. Attackers (or malicious content ingested by an agent) use instruction-override, DAN/developer- mode, system-prompt extraction, and safety-filter bypass phrasing to coerce GenAI coding agents and automation wrappers into running attacker-chosen commands. When that injected text reaches a child shell or interpreter, it is a strong signal that untrusted prompt content is crossing into local code execution, enabling credential theft, data exfiltration, persistence, or further tool abuse under the user's privileges.

==== Investigation guide



*Triage and analysis*



*Investigating Potential Prompt Injection Coercing Shell Execution*


A shell or scripting interpreter started with a parent command line that matched common jailbreak /
instruction-override language (for example "ignore previous instructions", DAN/"Do Anything Now", or
"bypass the safety filter"). This can indicate a GenAI agent or wrapper being coerced by untrusted prompt
text into local code execution. The alert is a content heuristic on command-line text — confirm whether the
strings are adversarial injection versus security testing or documentation.


*Possible investigation steps*


- Review `process.parent.command_line` and `process.command_line` for the matched jailbreak phrases and the
  surrounding payload (paths, URLs, credentials, download/execute patterns).
- Identify the parent process tree (`process.parent.name`, `process.parent.executable`) and whether it is a
  known GenAI client (Claude, Cursor, Codex, Copilot, Windsurf, etc.) or a shell-snapshot wrapper.
- Correlate with other GenAI-related alerts on the same `host.id` / `user.name` in the same window
  (unsafe permission bypass, suspicious shell via GenAI client, credential-path access).
- Check recent GenAI config or MCP changes and any outbound network activity from the same process tree.
- Determine whether the activity aligns with approved red-team / detection-engineering work.


*False positive analysis*


- Approved red-team, evaluation, or detection-engineering tests that deliberately include jailbreak
  strings. Exclude known lab hosts or users.
- Claude Code / similar agents wrap user commands in `zsh -c` / `bash -c` shell-snapshots, so the phrase may
  appear in both parent and child command lines for a single user action.


*Response and remediation*


- If not an approved test, isolate the host/user session, review the GenAI conversation or agent history for
  the injection source, and rotate credentials accessible to that user.
- Audit GenAI tool configs, MCP servers, and skills loaded during the session.
- Block or restrict the responsible agent/automation if compromise or successful coercion is confirmed.
