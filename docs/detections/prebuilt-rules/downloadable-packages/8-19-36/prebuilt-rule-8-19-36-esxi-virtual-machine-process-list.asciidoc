=== ESXi Virtual Machine Process List

Detects `esxcli vm process list` on an ESXi host. The command lists running virtual machines and the world IDs of their `vmx` processes. Those IDs are what a later kill command uses to stop the VMs and release the locks on their virtual disks.

==== Investigation guide



*Triage and analysis*



*Investigating ESXi Virtual Machine Process List*


esxcli vm process list enumerates running virtual machines and their world ids. A later kill command uses those world ids to stop the VMs.


*Possible investigation steps*


- Read message for a plain list versus a list piped into vm process kill.
- Check the same session for pkill, power.off, snapshot removal, or a search for vmdk files.
- Confirm with the virtualization owner whether the list was part of a scheduled check.


*False positive analysis*


A standalone list during a change window is commonly benign. A list immediately followed by a force kill of every world id is the shutdown step before encryption.


*Response and remediation*


- If the same session kills virtual machines or deletes snapshots, isolate the host.
- Otherwise record the account and source for hunting on other hosts.
