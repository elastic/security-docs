=== GitHub Private Repository Forking Enabled

Detects enabling of private repository forking on a GitHub organization. Allowing forks of private repositories lets code leave the organization into personal forks, which is a common collection path after an org-owner compromise.

==== Investigation guide



*Triage and analysis*



*Investigating GitHub Private Repository Forking Enabled*


`private_repository_forking.enable` is an organization policy change. Follow with `repo.fork` if present.


*Possible investigation steps*


- Identify `user.name`, `github.org`, and `github.actor_ip`.
- Check whether private repos were forked afterward and to which accounts.


*False positive analysis*


- Approved inner-source programs that temporarily enable forking.


*Response and remediation*


- Disable private repository forking unless required. Review forks created in the same window and transfer or delete unauthorized copies.


==== Rule query


[source, js]
----------------------------------
from logs-github.audit-* metadata _id, _index, _version
| where
  event.module == "github" and data_stream.dataset == "github.audit"
    and event.action == "private_repository_forking.enable"
| keep
    _id,
    _index,
    _version,
    @timestamp,
    event.action,
    user.name,
    github.org,
    github.repo,
    github.actor_ip,
    github.hashed_token,
    github.programmatic_access_type,
    github.user_agent,
    github.visibility
